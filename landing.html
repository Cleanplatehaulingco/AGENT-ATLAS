What this application does

Built for one shop.
Engineered to last.

Agent Atlas is a private internal tool built and operated exclusively by the owner of TradeOpsVault to manage a single Etsy digital download shop.

Listing Management
Draft, edit, and publish all 20 listings to TradeOpsVault with consistent formatting, optimized titles, and full tag sets.
  • Create and update listings via Etsy API
  • Manage titles, descriptions, 13-tag sets
  • Set pricing, categories, digital file flags
  • Pipeline view from draft to live
Image Publishing
Generates and uploads up to 10 product images per listing using canvas compositing and DALL-E 3. Fills every Etsy image slot in the correct rank order.
  • Hero, detail, bundle, and infographic slides
  • Uploads to correct Etsy rank slots (1–10)
  • Canvas compositor — no external services
  • DALL-E 3 HD for lifestyle shots only
Revenue Tracking
Reads TradeOpsVault's own transaction history to track revenue against a 45-day $500 goal. No competitor data, no third-party shops.
  • Reads own transactions via transactions_r scope
  • CSV import from Etsy order export
  • Pace tracking against goal timeline
  • Per-listing revenue breakdown
Listing Launcher
A bookmarklet tool that auto-fills Etsy's add-listing form from prepared data — reducing manual entry from 10 minutes to under 30 seconds.
  • Fills title, description, tags, and price
  • Data relay via secure server endpoint
  • No scraping — user-initiated only
  • Works on etsy.com/sell/add-listing
Workflow

From draft to live in minutes

01
Draft Listing
Write title, description, and tags in the Atlas listing editor. AI suggests optimized copy for the TradeOpsVault catalog.
02
Generate Images
Canvas compositor builds all 10 Etsy image slots automatically. DALL-E 3 generates lifestyle and before/after shots.
03
Compliance Check
Automated scan checks titles, tags, and descriptions against Etsy policy rules before publishing.
04
Publish to Etsy
One click creates the listing and uploads all images via the Etsy API in the correct rank order.
